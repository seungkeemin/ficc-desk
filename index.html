ficc-desk.

A one-person, local dashboard for running a FICC trading desk routine.

Rates, FX and credit on one screen — next to the log that says whether the discipline held. No real money: every position is paper. The output is not P&L, it is the record.

Python 3.14 · FastAPI · SQLite 51 fields on one screen 157 tests no build step

Static reproduction with fixture data — not live market values. The interface is in Korean. Left to right: last night's session review, the market snapshot, the routine checklist; then the position blotter and, bordered in amber, the invalidation watch.

02How it works

What it collects

ECOS · Bank of Korea16
FRED · St. Louis Fed13
KRX Data Marketplace5
Manual entry7
Derived on read10
On screen51

Collected three times a day into a local SQLite file. 41 stored, 10 computed on read and never written. A field stays manual until a real API call proves the endpoint — DXY has no free API, so it is typed in rather than faked from a different index.

Seven rules

  1. Missing is never zero.
  2. Derived values are never stored.
  3. API specs are never guessed.
  4. The observation log is append-only.
  5. No vault file is ever deleted.
  6. Collection failure is a normal condition.
  7. No idea without an invalidation condition.

The dashboard is disposable; the time series is not. Breaking one of these corrupts data quietly rather than raising an error.

Run it

FastAPI · Jinja2 · SQLite (WAL) · plain JS · pytest 157
No Node, no ORM, no build step.

python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env
.venv\Scripts\python -m uvicorn ficc.app:app --port 8787

Migrations apply themselves on boot. Empty keys are fine — that source is skipped and every other one still collects.

Design. Zero corner radius, no shadows, no gradients, one amber accent used by area in exactly one place — the invalidation watch. Colour shows direction, never judgement: a rate going up is neither good nor bad, and the up-red / up-green convention is a setting. Nothing is gamified — the streak is a bare number, and an empty state gives the next command instead of an apology.

No real money. Every position is paper. The point is the record, not the return.
