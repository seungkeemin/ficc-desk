ficc-desk.

A one-person, local dashboard for running a FICC trading desk routine.

Rates, FX and credit on one screen — next to the log that says whether the discipline held. No real money: every position is paper. The output is not P&L, it is the record.

Python 3.14 · FastAPI · SQLite 51 fields on one screen 157 tests no build step
Repository SPEC.md — design CLAUDE.md — rules

01The screen

Eight panels on a fixed grid, sized so a whole working day fits in one viewport. The page never scrolls; only the inside of a panel does. Every number is entered or corrected in place — click the value, type, it saves.

Static reproduction with fixture data — not live market values. The interface is in Korean. Reading across: last night's session review, the market snapshot, today's routine checklist; then the one-sentence "why did it move", the event calendar with my call recorded before the print; then the position blotter and — bordered in amber, the only place the accent colour is used by area — the invalidation watch.

02What it does

Three times a day a scheduled task pulls every field it can from three public APIs into a local SQLite file. Whatever has no free public source is typed in by hand. Spreads are never stored — they are computed when the page is drawn, from whichever inputs actually exist.

SourceFieldsWhat it covers
ECOS — Bank of Korea16 Base rate, KOFR, CD/CP 91D, MSB 1Y, KTB 1–30Y, corporate AA-/BBB- 3Y, USD/KRW, KRW/100JPY, KRW/CNY
FRED — St. Louis Fed13 UST 3M–30Y, SOFR, fed funds target upper, 10Y breakeven, US IG/HY OAS, USD/JPY, EUR/USD, VIX
KRX Data Marketplace5 KTB futures 3/10/30Y close and open interest 3/10Y — called once a day, response cached
Manual entry7 KRW IRS 1/3/5Y, 1M NDF, 1M FX swap point, DXY, Korea 5Y CDS — no free public source exists for these
Derived on read10 Curve spreads, bond–swap, credit spreads, the KR–US 10Y differential — never written to the database
On screen5141 stored · 10 derived

A field stays manual until a real API call proves the endpoint. DXY is the clearest case: it is an ICE proprietary index with no free API, and the broad dollar index on FRED is a different number with different weights — so it is not quietly filled in under a label that would be a lie.

03Seven rules

The dashboard is disposable; the time series is not. These are the invariants the code is written against — breaking one corrupts data quietly rather than raising an error.

  1. Missing is never zero.If a value was not collected, no row is written and the cell reads "not collected". "There is no value" and "the value is 0" are never mixed.
  2. Derived values are never stored.Spreads are computed on read. If any input is missing the result is None — never substituted with 0.
  3. API specs are never guessed.Series codes and endpoints enter the config only after a real call confirms them, annotated with the date they were verified.
  4. The observation log is append-only.No UPDATE, no DELETE, under any circumstance. Every overwrite of a value is recorded there instead.
  5. No vault file is ever deleted.The Obsidian .obsidian/ directory is neither read nor written.
  6. Collection failure is a normal condition.One dead source does not kill the run. Successful fields are stored; failures land in a result table with the reason.
  7. No idea without an invalidation condition.At least one is required, enforced at the application level. A thesis you cannot be wrong about is not a thesis.

04Design

Not a dark theme — a discipline for information density, borrowed from real FICC terminals. Corner radius is zero, there are no shadows and no gradients, and the accent is a single amber used by area in exactly one place: the invalidation watch.

Colour shows direction, never judgement

  • A rate going up is neither good nor bad. Up red / down blue is the Korean convention and the default; up green / down red is the Bloomberg one. It is a setting, and neither palette implies an opinion.
  • "Broken" is marked by shape as well as colour — inverted background plus a 3px left bar — so it does not depend on which direction palette is active.

Nothing is gamified

  • The streak is a bare number. No badge, no celebration, no warning when it breaks.
  • No welcome message, no motivational copy, no emoji, no illustration.
  • A value flashes once for 150ms when it updates. That is the only animation, and prefers-reduced-motion removes it.

Empty states give the next command

  • Not "No data yet :(" but "Today's snapshot not collected — python -m ficc.ingest".
  • Not an apology but an instruction: "No active position — write Wednesday's idea".

05Stack

Every dependency carries one line of justification in SPEC.md. The constraint that shaped the list: it has to still run in a year, on this machine, without a build step.

LayerChoiceWhy
WebFastAPI + UvicornType-hint validation stops unit and typo errors at the entry point, where the manual fields come in
TemplatesJinja2, server-renderedOne screen, almost no state — an SPA would add a build step just to check a refresh
Interaction~200 lines of plain JSInline edit, debounced save, one flash. A framework here would not survive a year of neglect
DatabaseSQLite, WALA single file, so a backup is a file copy — the easiest way not to lose the series
MigrationsNumbered .sql + schema_versionAlembic is too much for a one-person local DB, and schema history reads better as text
SchedulingWindows Task SchedulerAn OS primitive — no resident process, and it runs whenever the machine is on
Testspytest — 157Derived values, backfill and export idempotency. UI tests would not pay for themselves here

Deliberately not used

Docker · PostgreSQL · authentication · an ORM · Tailwind · any frontend build tool · state management · WebSockets · Node.js. In a one-person local app, every one of them is pure maintenance cost.

06Run it

Windows, Python 3.14. Migrations apply themselves on boot, so there is no database setup step.

# create the environment and install
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
# copy the key template and fill in whatever you have
copy .env.example .env
# serve on 127.0.0.1:8787
.venv\Scripts\python -m uvicorn ficc.app:app --port 8787 --reload
# collect once
.venv\Scripts\python -m ficc.ingest

Empty keys are fine. A source with no key marks its fields "no key" and is skipped — the run does not die, and every other source still collects. Nothing you have to sign up for is required to see the screen.

No real money. Every position is paper. The point is the record, not the return.
